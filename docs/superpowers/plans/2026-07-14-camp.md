# Camp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the complete Linux lifecycle CLI described by `prompts/camp-codex-build-prompt.md`, using the Oracle-corrected recoverable publication protocol and the direct user override to `skevetter/devpod` v0.26.1.

**Architecture:** Camp is one Go/Cobra binary organized as pure domain invariants, application use cases, ports, and external adapters. Every external side effect is journaled as intent then verified fact; immutable generations, lineage-scoped leases, explicit materialization ownership, a persistent supervisor, and reconciliation states make publication and cleanup independently recoverable.

**Tech Stack:** Go 1.24+, Cobra, YAML v3, AWS SDK for Go v2, klauspost zstd, DevPod v0.26.1, Hauler v2.0.1, Linux amd64/arm64.

## Global Constraints

- The capsule is the complete adopted root; exclude exactly `.camp/build/` and `.camp/runtime/` from the inner archive.
- `.camp/hauler-manifest.yaml` is the packing contract; do not introduce another bundle format.
- DevPod owns providers, SSH, IDEs, credentials, tunnels, forwarding, and workspace lifecycle.
- Hauler owns OCI-layout stores, saved hauls, registry serving, and file serving.
- No background filesystem synchronization; only explicit `sync` and `close` return workspace bytes.
- Never remove an adopted user directory. Remove a Camp-created XDG materialization only after verified publication, DevPod teardown, forwarder/service shutdown, conditional lease release, and ownership revalidation.
- Lock `skevetter/devpod` v0.26.1 at `86b6f9f5d6713fecdeff5dd240e775a8c7e8d44e`; amd64 SHA-256 `01bbc2d88090d546e04aa435c63fc5eb95ec49ffb7ab102a67de0d6d12c82d8d`; arm64 SHA-256 `268621da428ca6d470d1812d63c9e41a1681b681861fc984648a57c5725478ee`.
- Lock `hauler-dev/hauler` v2.0.1 at `4f47155d6f8ccec22ba6f609f2f1f4919b02fce1`; amd64 SHA-256 `c8b65ea57f10a03f02104ebbecbf1249c41f499bc85771488824b70f6ccfc76c`; arm64 SHA-256 `ffe9811bbb77f844200f0644b98a08b65ee2d5ffcc0e2b49b1df31719a0a052f`.
- Lock the Room of Requirement fixture v1.18.0 at `0aabf18ad291c590498bd8e904a7d09f66378b85`.
- Existing root devcontainer configuration wins. Generate the digest-locked Wolfi fallback only under `.camp/runtime/`.
- Preserve every named OCI image and direct tagged registry push. Do not promise capture of dangling layers, opaque BuildKit cache, untagged manifests, digest-only objects, or arbitrary OCI artifacts.
- Every durable schema is versioned. Every secret-bearing file is mode 0600. Stable JSON and human presenters consume the same typed events and operation results.
- Treat ambiguous subprocess, upload, pointer, DevPod, and cleanup outcomes as reconciliation states; never retry destructive operations blindly.
