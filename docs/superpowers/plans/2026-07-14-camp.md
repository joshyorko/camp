# Camp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the complete Linux lifecycle CLI described by `prompts/camp-codex-build-prompt.md`, with the direct user override that Camp uses `skevetter/devpod` v0.26.1.

**Architecture:** Cobra handlers call a single application service whose lifecycle controller persists every transition. DevPod, Hauler, storage, subprocesses, clocks, services, archives, and image engines sit behind narrow interfaces so safety behavior and exact argv remain testable.

**Tech Stack:** Go 1.24+, Cobra, YAML v3, AWS SDK for Go v2, klauspost zstd, DevPod v0.26.1, Hauler v2.0.1, Linux amd64/arm64.

## Global Constraints

- The capsule is the complete adopted root; exclude only `.camp/build/` and `.camp/runtime/` from the inner archive.
- `.camp/hauler-manifest.yaml` is the artifact contract; do not introduce another bundle format.
- DevPod owns providers, SSH, IDEs, credentials, tunnels, and port forwarding.
- Hauler owns stores, saved hauls, registry serving, and file serving.
- No background filesystem synchronization; `sync` and `close` are explicit checkpoints.
- Never delete local materialization until upload, remote verification, and latest-pointer compare-and-swap all succeed.
- Lock DevPod v0.26.1 at commit `86b6f9f5d6713fecdeff5dd240e775a8c7e8d44e` and Hauler v2.0.1 at commit `4f47155d6f8ccec22ba6f609f2f1f4919b02fce1`.
- Honor an existing root devcontainer configuration. Generate the digest-locked Wolfi fallback only under `.camp/runtime/`.
- Preserve all named OCI images. Treat registry catalog ingestion as tagged-image retention, not arbitrary OCI-registry backup.
- All extraction, config, journal, lease, and cleanup paths must be traversal-safe, symlink-safe, permission-safe, and interruption-safe.
